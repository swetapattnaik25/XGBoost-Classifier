# XGBoost Classifier for Breast Cancer Prediction

## Overview

A machine learning project using XGBoost to classify breast tumors as benign or malignant using the Breast Cancer dataset.

## Technologies

- Python

- XGBoost

- Scikit-learn

## Features

- Train-test data splitting

- XGBoost model training

- Model evaluation using accuracy, classification report, and confusion matrix

## Objectives
- Understand and implement the XGBoost classification algorithm.

- Split the dataset into training and testing sets.

- Train an XGBoost classifier using selected hyperparameters.

- Evaluate the model using accuracy, classification report, and confusion matrix.
